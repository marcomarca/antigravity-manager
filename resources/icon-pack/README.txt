Antigravity icon pack
=====================

Source
------
Based on option 1 selected by the user (Orbit A concept).
Original generated source: a_clean_high_contrast_app_icon_logo_style_graph_1.png

Included outputs
----------------
- master/: original source and practical cropped/transparent masters
- png/: generic square PNG exports in common sizes
- windows/: multi-size ICO plus common PNG sizes, including tray-icon.ico
- web/: favicon.ico, favicon PNGs, apple-touch-icon, android-chrome PNGs
- android/: mipmap launcher PNGs plus 512 px Play Store asset
- ios/: common iOS app icon PNG exports
- macos/AppIcon.appiconset/: Xcode-ready macOS app icon set with Contents.json
- macos/app-icon.icns: included if the local encoder succeeded

Notes
-----
1. The practical exported set uses a cleaned master with transparent outer corners,
   preserving the rounded-square icon while removing the black corner fill.
2. Sizes were exported with high-quality Lanczos resampling.
3. Small sizes received a light sharpening pass for better legibility.
